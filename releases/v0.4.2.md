# Photoshop 局部改图 v0.4.2

在 Photoshop 中读取框选／套索区域，结合修改要求和参考图生成候选结果，再按原坐标添加为独立图层。此版汇总了从初始版本以来的模型、上传、任务管理与界面优化。

## 新功能与优化

- **从 LK888 API 同步模型**：支持完整模型库、搜索、分页和收藏，优先呈现图像编辑模型；同步失败保留缓存。按用户偏好排除 Token 计费版本，非图像模型禁止用于改图，未知能力会明确提示。
- **按模型匹配参数**：根据平台参数定义提供清晰度、比例和附加选项，校验必填参数、可用规格及参考图数量，不再给所有模型套同一套参数。平台账号实际可用渠道和模型能力以 API 返回为准。
- **选区上传自动压缩**：先进行 PNG 无损压缩；超过单张上传预算时自动等比缩小。面板显示上传尺寸和大小，回填仍保留原选区坐标及蒙版。此自动处理针对 PS 读取的选区图，外部参考图超限需先自行缩小；等比缩小可能损失细节。
- **多选区任务管理**：顶部标签区分待生成、提交中、生成中、已完成、失败和待确认；关闭标签保留历史。生成其他选区或再次生成时保留旧任务，历史恢复提示词、图片与参数。
- **性能优化**：查询并发限制为 3，批量保存查询结果；未变化的标签和结果不重复重建；使用小缩略图，编码后释放 Photoshop 像素对象，减少重复写入和图像解码。
- **提交状态更清楚**：模型名称、选项和提交 ID 使用同一状态；已提交记录保留实际模型。网络异常导致结果不确定时阻止直接重复生成；批量部分失败保留成功提交的任务，剩余任务不自动重试。
- **统一界面与交互**：统一按钮、间距、字体和卡片；选区与参考图在读取前后保持同排等高；输入区与底部工具栏重新布局；短面板可滚动，空格不再误开下拉菜单。首次读取选区保留已填写要求和参考图。
- **结果与输入操作**：添加、粘贴和拖入参考图，支持图片标注；候选图可放大、保存原图或反复添加为独立图层。导入检查原文档与画布尺寸，原选区蒙版限制回填范围。
- **语音平台提示**：Windows 可连接本机中文听写助手；Mac 显示“听写帮助”，使用系统听写。当前没有云端语音识别 API 或 Mac 一键录音助手。

## 下载与安装（支持 OpenUXP）

下载本页 Assets 中的 **`ps-local-edit-LK888-0.4.2.ccx`**。GitHub 自动生成的 Source code 压缩包是源码，不是直接安装包。

1. 安装 [OpenUXP Installer](https://moonvy.com/apps/upx-installer/)（第三方开源工具，提供 macOS 和 Windows 版，支持 UXP `.ccx`）。
2. 保存正在编辑的文件并退出 Photoshop，将上述 `.ccx` 拖入 OpenUXP，核对插件名称“局部改图”、版本 0.4.2 和宿主 Photoshop，然后安装。
3. 如官方安装方式无法安装此未签名本地包，可使用 OpenUXP 提供的侧载方式。具体按钮与可用方式以所用 OpenUXP 版本为准。
4. 重新打开 Photoshop，在“增效工具”中打开“局部改图”，进入设置保存自己的 LK888 API Key，检查连接并同步模型。

也可尝试双击 `.ccx` 通过 Creative Cloud 安装；开发者可用 Adobe UXP Developer Tool 加载源码中的 `plugin/manifest.json`。OpenUXP 支持的格式和方式见其官网，本包已由用户完成 OpenUXP 实机安装验证。

## 使用与兼容说明

- 清单要求 **Photoshop 25.0（2024）及以上**。使用 RGB 文档；不同 Photoshop 版本仍需实际验证。需要 LK888 账号和额度，生成费用由平台收取，一次生成多张会创建多个平台任务。
- Windows 本机语音、标注及部分剪贴板／拖入辅助功能需要单独启动源码中附带的助手，**CCX 不包含助手**。在已安装 Node.js 的 Windows 上，解压源码，在项目目录运行 `node scripts/voice-server.cjs`，保持终端开启；中文听写还需要系统中文识别引擎和麦克风权限。旧 `打开局部改图插件.cmd` 入口依赖原开发环境路径，不适合作为通用安装入口。
- Mac 语音：系统设置 → 键盘 → 听写，启用中文后，聚焦修改要求并使用系统配置的快捷键。插件按钮提供使用帮助，不会直接启用麦克风。
- API Key 保存在本机安全存储。生成时提示词和输入图像发送至 LK888；输入 PNG 压缩不等于模型输出或回填完全无损。
