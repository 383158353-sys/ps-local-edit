# Photoshop 局部 AI 改图插件

Photoshop 内的简洁 UXP 面板，通过 https://api.lk888.ai 调用生图模型，使用 PS 原生选区完成局部修改。

## 功能

- 框选或套索读取选区，紧贴选区捕获参考画面并保留原选区蒙版。
- 添加、拖入或粘贴截图作为编号参考图。
- 输入修改要求，选择模型、清晰度、尺寸及 1–4 张结果。
- 多处改图可后台生成；顶部标签切换，关闭后在历史记录恢复。
- 结果点击添加独立图层，按原坐标和尺寸回填；允许重复添加。
- 图片右上角放大预览，预览内下载或右键保存原图。
- 从 API 同步模型，支持搜索、收藏和能力优先排序；已声明为非图像的模型不能用于改图，未标注能力的模型会显示待确认。同步失败保留本机缓存或内置预设。
- 语音按钮启动本机 Windows 中文听写，再点停止；文字插入修改要求。需启动本机语音助手，音频不上传到模型 API。

## 安装

需要 Photoshop 25.0 或更新版本。目前本机 Photoshop 27.6 已加载，用户已进行实际生成与图层回填；不同宿主和模型仍需自行验证。

1. 尝试双击 `dist/局部改图-LK888-0.4.0.ccx` 使用 Creative Cloud 安装。
2. 若本地 CCX 无法安装，通过 Adobe UXP Developer Tool 添加 `plugin/manifest.json`，点击 Load。
3. 在 PS 增效工具中打开面板，进入设置填写并保存自己的 LK888 API Key。
4. 在 RGB 文档选择区域，点击更新选区，输入要求后生成。
5. 生成完成后点击候选图添加图层。放大查看与添加操作分开。

Windows 上也可运行 `scripts/install-plugin-autoload.ps1` 添加登录启动项。启动后它会在 Photoshop 每次打开时重新注册开发版插件，无需手动运行 `打开局部改图插件.cmd`。这是本机开发加载的自动恢复入口，不等于 Adobe Marketplace 正式安装。

密钥保存在本机 UXP secureStorage。模型 ID 以 LK888 API 返回为准；若某预设 ID 与账号提供的模型 ID 不一致，可在设置页配置自定义 ID。模型可用性、速度及费用以平台账号为准。一次生成多张会提交多个任务。

## 开发

核心测试无需额外依赖，使用 Node.js 执行：

```sh
node --test tests/*.test.cjs
```

跨平台打包（Python 3，无额外依赖）：

```sh
python3 scripts/package.py
```

Windows 也可以使用：

```powershell
./scripts/package.ps1
```

浏览器检查脚本使用 Playwright；本机版本引用了本地运行时路径，其他环境需调整引用。

## 边界

生成与添加图层分开。历史保存输入和结果，但导入时必须回到原文档，画布尺寸变化会阻止自动导入。输入图片和提示词发送到 LK888；图片下载不附带 API Key。原选区蒙版限制显示区域，模型可能改变区域内构图。输入 PNG 无损编码，结果保存模型原始文件；回填缩放和模型输出分辨率仍会影响显示细节。

## 本机语音输入（Windows）

使用系统已安装的中文语音识别引擎，需允许桌面应用访问默认麦克风。先打开 PS，再双击根目录的 `打开局部改图插件.cmd`，该入口会启动本机语音服务并加载插件。服务仅监听 `127.0.0.1:17402`，只在点击语音时启用麦克风；再次点击停止，每次最多 60 秒。识别失败会显示原因，不会调用生图 API。关闭或切换改图、提交生成时会停止当前听写。离线引擎的识别质量取决于麦克风和语言包；也可使用 Win+H 或输入法听写。

## 输入框与粘贴

修改要求使用 PS 原生文本框，后台查询不会重建顶部标签或覆盖输入内容。Ctrl+V 或输入框右键菜单的“粘贴”可插入文字；复制的截图会添加为参考图。纯文字使用 UXP 剪贴板接口；截图读取通过本机 Windows 助手，仅在用户执行粘贴时读取剪贴板，不上传到识别服务。

## 0.1.1 更新

- 顶部工具栏使用原生 UXP 控件，移除外层重复绘制的背景与边框。
- 选区使用真正的无损 PNG 压缩。压缩后仍超过单张 10 MiB 上传预算时，自动等比缩小，直到满足限制。预算包含 Base64 数据与 data URL，上传前再次校验；提示会显示上传尺寸与大小。缩小会损失部分细节，原文档与回填蒙版仍保留原尺寸，提示词中的范围坐标同步换算。此自动处理针对 PS 读取的选区图，外部参考图超过限制仍需手动缩小。
- 标签显示待生成、提交中、生成中、已完成、失败或待确认；关闭标签只收起，历史保留。更新已有任务的选区会建立新记录，再次生成也会保留旧任务。
- 查询最多 3 个并发，同一轮只保存一次；未变化的结果不重建卡片，移除结果原图预下载。选区编码后释放 Photoshop 像素对象，未变化的图片与蒙版不重复写入。

本版本的新增流程有自动测试覆盖；按钮在 Photoshop 原生宿主的视觉表现和多选区实际流畅度仍需实机验证。

## 0.2.0 界面更新

按深色面板设计重新组织界面：顶部选区卡片带独立小缩略图和任务状态；中间为选区大预览、上传大小、参考图区与修改要求；底部集中展示生成结果和添加图层操作。新建、更新选区、重新生成和历史入口保留，原始选区蒙版及 10 MiB 上传处理流程不变。

默认面板宽度调整为 420 像素，也可缩至 280 像素。选区卡片支持 Enter/空格切换，关闭后保留历史。旧记录没有缩略图时显示占位符，无需读取完整大图。

运行 `node scripts/preview.cjs` 生成 `dist/panel-preview.html`。使用本地 HTTP 服务打开该文件，`?demo` 展示模拟任务，`?empty` 展示空状态；预览运行同一份界面控制代码，使用内存中的模拟 Photoshop、文件和模型接口，不访问真实密钥和付费 API。浏览器里的原生控件外观仅为近似，Photoshop 宿主显示仍需实机确认。

## 0.2.1 紧凑布局

选区图（图片 1）、参考图和添加入口合并为一行，多张图片横向滚动。顶部任务卡片也改为横向滚动，避免新增选区拉长页面。移除重复标题和完成提示，收紧间距；结果区限制高度并可独立滚动。修改要求默认保持紧凑，点击展开按钮可全屏编辑，Escape 收起。小窗口进一步缩小缩略图，窄面板把选区尺寸移至图片提示信息中；上传大小和压缩状态仍显示。

## 0.3.0 API 模型同步与收藏

- 启动后及保存密钥后，使用本机 secureStorage 中的密钥读取 `GET /v1/models`。设置页可手动同步，搜索名称或 ID，按图像优先、仅收藏、全部模型筛选，并直接选择模型。模型项或编辑区 ☆ 可添加收藏，★ 可取消。
- 缓存和收藏按当前密钥的本地指纹区分；不把 API Key 明文写入模型缓存。网络失败保留旧列表。切换密钥不复用另一个密钥的收藏。只有本次同步成功的模型进入新缓存，历史中的模型仍可显示并标记待确认。
- API 明确声明图片输入和图片输出、或声明图片编辑能力时，优先作为编辑模型显示。已有七项预设保留为离线后备。名称匹配只作为候选，不作为已验证能力；已明确不支持图片输入／编辑，以及非图像模型会在提交前被拦截。
- 保留 API 返回的能力和参数元数据。支持 `parameter_schema.properties`、`parameters`、`supported_parameters` 的字段与枚举，按模型选择 `image_size`／`resolution`／`size` 和 `aspect_ratio`／`ratio`。像素尺寸枚举按当前比例和分辨率选取可用尺寸。界面仅显示适用选项，参考图数量遵守 API 声明的 `max_images`（含选区图）。
- 没有参数声明的新增模型使用平台默认参数；已有预设保留原参数方式。只有 `size` 字段却未给出枚举时，不推测尺寸格式。明确声明仅适用其他专用接口的模型会提示尚需适配，不会自动改换接口重试，以免重复提交。

此版仍使用 LK888 的 `/v1/media/generate` 与 `/v1/media/status` 任务协议。同步列表不等于所有模型已兼容；平台如果只返回模型 ID，插件无法确认编辑能力或获知每个模型完整参数。专用协议、新的必填参数需要依据该模型的平台文档继续添加适配。当前新增功能已通过自动测试和浏览器模拟验证，尚未使用用户密钥进行真实同步或付费生成实测。


## 0.3.1 API 检查稳定性修复

- 检查 API 只发送鉴权查询、更新检查结果，不再刷新编辑界面、重建原生下拉菜单或处理图片。检查、同步与保存密钥共用请求锁，重复点击不会叠加请求。
- 编辑界面刷新时复用内容相同的原生菜单。模型管理改用普通按钮，避免点击时销毁正在派发事件的原生控件。
- 启动和保存密钥后读取本机模型缓存；需要更新时在设置中点击「从 API 同步模型」。此行为取代 0.3.0 的自动同步。
- 编辑区下拉框最多显示 40 个优先模型及当前模型；设置页显示前 20 个匹配结果，通过名称或 ID 搜索可选择缓存中的其他模型。搜索不会重建编辑区菜单。
- 自动测试覆盖重复点击、检查失败恢复、菜单复用及 2000 个模型的显示上限。仍需在 Photoshop 原生环境验证，无法仅凭界面日志确认原生崩溃根因。


## 0.3.2 检测状态与完整模型库

- 连接检测结果独立显示，不被模型同步、搜索或切换页面覆盖。检测时间按密钥对应的本地指纹保存；重启后明确显示上次结果，本次仍需重新检测，切换密钥不会沿用旧结果。
- 检测鉴权成功后顺序同步 API 模型，仍共用请求锁；同步失败不会把鉴权成功误显示为失败。启动和保存密钥仍只读取缓存。
- 完整模型库默认显示全部模型、图像优先排序，提供每页 20 个的上一页/下一页和总数提示。编辑区的「全部模型」入口可访问全部已获取模型，常用下拉框仍有限制以避免原生菜单过大。
- 完整指 API `/v1/models` 实际返回并具有有效 ID 的模型；不表示全部模型都支持当前编辑协议，也不能保证平台返回了账号权限以外的模型。


## 0.3.3 模型切换与通用清晰度

- 从原生下拉菜单的选中序号与菜单项读取实际模型 ID，同步选中属性，不再将控件显示文字或旧 value 当作 ID。模型库选择、收藏重排、历史恢复和提交使用一致的选择状态。
- API 未提供参数说明的图像或待确认模型，可手动选择 1K / 2K / 4K，选项标为「通用」。手动选择后通过 LK888 通用 `image_size` 字段提交；具体模型是否支持或接受该字段仍以平台为准，插件不自动重试。
- 此类模型选择「自动」时仍省略清晰度字段，使用平台默认设置。有明确参数说明的模型继续按其声明的字段名与选项提交，不增加未声明的参数。
- 96 项自动测试通过，新增模拟原生控件 value 返回旧值、实际选择来自 selectedIndex、模型库选择待确认模型以及手动清晰度提交的回归测试。尚未进行 Photoshop 原生界面实测或付费生成验证。


## 0.3.4 LK888 分模型参数匹配

- 原协议参考客户端的模型参数实现：[generate.py](https://github.com/Corkery520/ComfyUI-MengBaoAI/blob/main/nodes/image_api/generate.py)，本次核对日期 2026-10-14。它是项目使用的开源客户端参考，并非平台官方文档或真实账号生成验证。
- Banana 2 / Pro 分别使用 `imageSize`、`aspectRatio`；Banana 2 另带默认 `thinkingLevel=minimal`，支持 0.5K。两者按各自比例列表显示，不共用通用参数名。
- GPT 图 2 使用 `size` 固定像素表，例如 2K + 16:9 → 2560x1440；GPT 图 2.5 使用 `resolution`、`aspect_ratio` 和参考客户端默认版本 flare。四类均按单张任务 `n=1` 提交，面板张数仍通过多个独立任务实现。
- `/v1/models` 仅返回 ID、能力或空参数列表时保留平台适配；非空参数声明优先。缓存中旧的空参数元数据不会让已知适配丢失清晰度；显式参数 schema 仍保留。API 元数据中的 camelCase 字段也可识别。
- 即梦 5 Pro、GK Image 2、千问 Max 沿用原有预设，尚未依据本次参考客户端核实；新增模型依 API 声明或保持待确认，不将全部模型笼统标为已匹配。
- 102 项自动测试通过，包含四类模型同步、清晰度选择及最终请求字段的完整链路。未使用用户密钥进行真实或付费生成测试。


## 0.3.5 平台官方目录与参数详情

- 找到并核对了[平台公开文档](https://eat.lk888.ai/apidoc)，文档配置明确指向 `https://api.lk888.ai`。本次公开文档列出 21 个图像模型；插件保留事实性参数快照供离线使用。
- 同步改用官方 `GET /v1/skills/models` 完整目录，再以最多 3 个并发请求读取图像模型 `GET /v1/skills/models/-?model=...` 详情。仅在新目录路由返回 404 时回退兼容 `/v1/models`；鉴权失败不会改用另一条路由掩盖错误。不会自动提交生图请求。
- 识别实际 `params[].name/label/type/required/options`，按平台字段与取值提交，包括小写 `1k/2k`、3K、`size` 表示比例的模型、必填生成质量等。当前密钥 `available_for_this_key=false` 与暂不可用规格在提交前拦截。
- 纠正即梦 5 Pro 为 `size=1K/2K`、GK 为 `resolution=1k/2k` 且最多 3 张参考图、千问为 `qwen-image` 且 `size` 表示比例。平台未声明清晰度的模型会明确显示「平台未提供」，不再虚构档位。
- 模型特有选项放在可收起的「模型参数」中，必填项自动展开。可选项默认不传，参数随选区任务保存并可从历史恢复。图像编辑参考图沿用原有选择/拖入操作。
- 请求同时检查 HTTP 状态与业务 code，避免把 HTTP 200 + code 500 误判成功。提交等待上限调整为平台建议的 300 秒；仍不自动重试创建任务。内联图片增加单张解码后 10MB、合计 30MB 的检查。
- 115 项自动测试通过，覆盖所有 21 个公开模型参数的枚举与请求字段、必填选项、密钥渠道限制、详情并发、旧路由兼容、上传总量和历史参数保存。未读取用户密钥进行真实账号查询，未付费生成；本机 Photoshop 原生加载与真实生成仍需验证。


## 0.3.6 选择状态重做与 Token 版排除（待用户审核）

- 用户截图显示原生菜单勾选、标题和读取到的索引并不一致。模型、清晰度、比例、张数与附加参数选择器改为插件自管状态及普通 DOM 选项面板；不再依赖原生控件的 value / selectedIndex / selected 属性或 DOM 包装对象身份；以固定控件 ID 保存状态。浏览器预览使用同一套控件，不另行模拟选择逻辑。
- 标题、模型提示、草稿、历史编辑状态和实际提交从同一个选择状态读取。已提交记录保留当时的 model / prompt / 参数，之后的编辑保存为独立 editor 状态；结果区显示实际提交模型。被移除的历史模型会要求重新选择，避免静默换回 Banana 2。
- 所有 Token 版从内置选项、远程目录、缓存、收藏与搜索中排除；手动填写 Token ID 也禁止提交。旧历史结果保留，可查看或回填。

- 成功结果只读取输出信息，跳过请求参数、输入图片和附件等回显字段；失败任务不把回显输入当成生成结果。
- 按用户要求，本版没有运行自动测试、界面测试、接口测试或生图验证。仅修改源码、构建交付文件和安装，结果交由用户审核。
